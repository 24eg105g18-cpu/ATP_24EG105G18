# Week 2

This folder contains Week 2 JavaScript projects and exercises that explore real-world programming patterns using arrays, objects, functions, and control flow.

## What’s in this week
- `temperatureanalyzer.js` — analyze temperature data and apply conditional logic
- `course names(functions).js` — manage course names and function-based data operations
- `grade marks.js` — calculate student grades and classify performance
- `building a shopping cart summary for an e-commerce website.js` — simulate cart totals and discount logic
- `Student Performance Dashboard.js` — combine student data into dashboard-style outputs
- `Employee Payroll Processor.js` — compute payroll, salary, and employee payment details
- `Movie Streaming Platform.js` — simulate a movie streaming UI with content and user flows
- `bank transaction analyzer.js` — analyze financial transactions and compute summaries
- helper and integration files: `app.js`, `app1.js`, `cart.js`, `discount.js`, `payment.js`, `product.js`, `task.js`, `validator.js`

## Technologies and concepts used
- JavaScript arrays and array iteration
- object structure and property access
- functions for reusable business logic
- conditional statements for real-world rules
- Node-compatible script execution
- basic module separation across helper files

## Learning goals
- organize code to model real applications such as shopping carts and payroll systems
- build reusable logic with functions and parameterized helpers
- process arrays of data to compute totals, minimums, and summaries
- validate inputs and calculate business results like discounts, grades, and transactions

## How to run these examples
1. open the `week-2` folder
2. install Node if it is not already installed
3. run any script from the terminal with `node <filename>.js`
4. modify values or add new scenarios to test different outcomes

## Recommended exploration
- inspect `cart.js`, `discount.js`, `payment.js`, and `product.js` to understand the e-commerce flow
- review `validator.js` and `task.js` for input validation patterns
- add a letter-grade conversion to `grade marks.js`
- enhance `bank transaction analyzer.js` to report totals by category
- expand `Employee Payroll Processor.js` with overtime or tax calculation logic

## Why this matters
Week 2 is about moving from simple scripts to structured problem-solving. These exercises show how to turn real-world requirements into code and how to keep logic organized for future extension.
