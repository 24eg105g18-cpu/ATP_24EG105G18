# Week 5

Week 5 is made up of a series of small assignments that help you practice specific skills.

What you’ll find:
- `assignment-1` through `assignment-8`
- each assignment folder contains a dedicated task or challenge

Why this week matters:
- these assignments help you focus on one concept at a time
- they are great for practicing problem-solving and organizing code
- each task is a chance to write clean, working JavaScript

How to use it:
- open each assignment folder and examine the code
- run the files, then modify them to support more cases
- if an assignment is missing a solution, try writing your own version

Suggested approach:
- read the instructions or filenames first
- test the existing code to understand what it does
- improve the code by adding comments, edge-case handling, or better naming
