# Week 1

Welcome to Week 1! This folder contains beginner JavaScript exercises that focus on core programming concepts such as comparisons, loops, functions, and array handling.

## What’s included
- `find-largest-of-two.js` — compare two numbers and identify the larger value
- `find-largest-of-three.js` — compare three values and return the greatest
- `sum-marks.js` — calculate the total of a list of numeric marks
- `find-smallest-element.js` — find the smallest element in an array
- `largest-of-three-function.js` — reusable function for finding the maximum of three numbers
- `sum-array-function.js` — reusable function that sums all values in an array
- `search-array-element.js` — search for a value inside an array and return its index

## Concepts used
- JavaScript variables, expressions, and constants
- comparison operators and conditional branches
- loops for iterating over arrays
- defining and calling functions
- returning results and displaying output
- basic debugging with console logs

## How to use this folder
1. open the `week-1` folder in your editor
2. inspect any `*.js` file to read the problem statement and logic
3. run the script with `node <filename>.js` from the terminal
4. modify input values or add new test cases to see different results

## How to extend these exercises
- add more test cases and edge-case handling
- rewrite functions to accept dynamic input arrays
- improve messages when values are equal or not found
- convert the scripts into reusable helper modules

## Why this matters
Week 1 is about making the first step from learning syntax to writing working code. These exercises help build confidence with conditional logic, loops, and functions — the foundation of every JavaScript program.
