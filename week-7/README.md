# Week 7

Week 7 is a full-stack project that brings together backend and frontend code for a blog-style application.

Folder structure:
- `Backend/` contains the server-side blog API and authentication logic
- `Frontend/` contains the React app for browsing and using the blog UI

What you’ll learn:
- how a frontend and backend work together
- how server routes provide data to a React app
- how authentication and media uploads can be handled in a full-stack project

How to use it:
1. open the `Backend/` folder to review the server code and API endpoints
2. open the `Frontend/` folder to review the React application structure
3. run both parts locally to see the full workflow in action

What to explore:
- backend authentication with JWT
- frontend routing and data fetching
- connecting the frontend to the backend API endpoints
- how the app manages state and user interactions
