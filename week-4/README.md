# Week 4

Week 4 is focused on HTML practice and simple web page structure.

What’s in this folder:
- sample HTML pages that show basic layout and link behavior
- examples of page content and navigation

What you’ll learn:
- how HTML file structure works
- how links connect pages together
- how content is organized using headings, paragraphs, and lists

How to use it:
- open the HTML files in a browser
- read the source to see how the page is built
- update text, links, or layout to experiment with simple page design

Friendly tip:
- duplicate one page and change the content to make a new example
- add a second link, list, or section to practice building webpages by hand
